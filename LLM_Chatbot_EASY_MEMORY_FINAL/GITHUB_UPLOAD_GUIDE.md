# GitHub Upload — Step by Step

## A. Create the repository

1. Go to GitHub and sign in.
2. Click **+** → **New repository**.
3. Repository name:
   `MUHAMMAD-ABUZAR-AI-SYSTEMS-ENGINEERING-LLM-CHATBOT`
4. Choose **Public** so the professor can open the repository without requesting access.
5. You can add a README, but if you are uploading this complete folder, avoid creating unnecessary duplicate files.
6. Click **Create repository**.

## B. Upload the project files

1. Open the new repository.
2. Click **Add file** → **Upload files**.
3. Open the extracted `LLM_Chatbot_EASY_MEMORY_FINAL` folder on your computer.
4. Select the project files/folders and drag them into GitHub, or use **choose your files**.
5. Make sure you are uploading the **contents of the project folder** so that `chatbot.py` and `requirements.txt` are visible at the repository root.
6. Enter commit message:
   `Initial AI Systems Engineering LLM chatbot`
7. Click **Commit changes**.

## C. Check the link

Your URL will be similar to:

`https://github.com/YOUR-GITHUB-USERNAME/MUHAMMAD-ABUZAR-AI-SYSTEMS-ENGINEERING-LLM-CHATBOT`

Copy the actual URL.

## D. Put the URL into the PDF

On page 1 of your report, replace the placeholder GitHub URL with your actual URL.

Example:

`GitHub Repository: https://github.com/abuzar123/MUHAMMAD-ABUZAR-AI-SYSTEMS-ENGINEERING-LLM-CHATBOT`

The **GitHub username is your GitHub account name**. You cannot put your real name in that part unless your GitHub username is actually your name.

## E. Important

Do not upload:

- `.venv/`
- `memory.json`
- API keys
- passwords
- private personal data
- huge model folders

The included `.gitignore` already ignores `memory.json`, virtual environments, and generated model folders.
