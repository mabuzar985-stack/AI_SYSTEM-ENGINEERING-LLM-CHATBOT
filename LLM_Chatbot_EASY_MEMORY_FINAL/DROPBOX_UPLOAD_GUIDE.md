# Dropbox Submission — Step by Step

The professor's submission instructions provide this Dropbox file-request link:

https://www.dropbox.com/request/bn2xesipitzy7uy5umcy

## What to upload

Upload the **PDF report**, not the GitHub ZIP as the main submission, because the professor's instructions specify a PDF report containing the GitHub link.

Before uploading, make sure:

- the first page has your real GitHub repository URL;
- the PDF filename uses your surname(s), e.g. `ABUZAR.pdf`;
- the GitHub repository is already public and contains the complete project.

## Upload steps

1. Open the Dropbox request link.
2. Click **Add files**.
3. Select **Files from computer**.
4. Select your final PDF, for example `ABUZAR.pdf`.
5. If Dropbox asks for your name/email, enter the information you want the professor to see.
6. Click **Upload**.
7. Wait for the green confirmation/check mark.

You do not need a Dropbox account to respond to a Dropbox file request.

## Deadline

Follow the exact deadline displayed in the professor's request/instructions. The professor's supplied instructions state that the request link expires **October 2 at 23:00**.
